# 03 · 研究实验方案与执行规范

> 状态：计划/未运行。该文件指导独立研究 FFNmotion，不代表已有 Wan2.1 的生成、训练或评测结果。版本：2026-11-17。

## 1. 要回答的问题与最小可信证据链

研究的主线是：

**头的视觉轨迹 → 真实 head 写入 → FFN/后续网络的响应 → 指定路径的因果效果 → 最终视频运动变化**。

不预设一定存在单一“运动神经元”，也不将 FFN 稀疏、速度提升或 Q1r2 近似误差作为优化目标。论文意义应来自一个可复核、可解释、可干预的运动计算路径。

| 层级 | 主要证据 | 尚不能推断 |
|---|---|---|
| 局部观察 | 头的 attention map、写入向量、FFN 通道增量 | 对最终轨迹有因果影响 |
| 模块机制 | 精确差分恒等式、单层路径恢复 | 整个生成过程的自然中介作用 |
| 下游作用 | 固定状态的 denoiser velocity 差异与路径 patching | 视频物理质量一定改善 |
| 生成行为 | 同种子配对生成、轨迹/事件/外观分析 | 在所有 motion prompt 上泛化 |
| 复核泛化 | 留出 prompt、seed、运动类型和可能的模型迁移 | 物理引擎式紧凑状态必然存在 |

## 2. 模型、采样与对照

主干：官方 Wan2.1-T2V-1.3B 的原始公开权重（BF16 推理；必要的局部计算临时转 FP32），30 blocks × 12 heads，1536 hidden，8960 FFN intermediate。

第一轮与作者的典型脚本对齐：**81 帧、832×480、50 步、sample_shift=5.0、CFG=5.0、UniPC**。这是初始实验配置；实际命令需按固定的 Wan 官方版本和作者 wrapper 检查后冻结。

- 同一 prompt/seed/sample schedule 比较所有 arms，保持模型、输入噪声、采样器初始状态、VAE 与解码设置一致。
- 显式比较 **cond-only、uncond-only、both**；不要默认 head patch 对 CFG 分支的调用顺序已经识别。
- 早期先固定真实采样状态并仅测一次 denoiser；有机制证据后再进行昂贵的完整视频生成。
- 以**运动指令遵循**和**物理合理性**为两个独立输出目标，另报告外观、物体持续存在、背景和镜头运动。

### 数据安排

**探索性受控条件**：篮球落下/反弹、物体沿斜坡滑动、物体匀速左右移动、静止对象。建议最初 4 个条件 × 2 个 seed（仅为功能探索，不是有统计功效保证的规模），结合论文中 seed 20 / 26 的篮球示例进行源结果复核。

**独立确认条件**：从未参与头/通道排序的 prompt、seed 和至少一个不同运动机制。确认集合在观察目标视频之前冻结；试验后不得用确认集重新挑选最优 head 再把同集作为独立证据。

**表征数据**：如需训练方向/速度 probe，另创建合成视频的真实数值标签。用原始 Wan VAE、正确的视频帧打包与匹配的 flow-matching 噪声日程得到训练输入。需同时在自由生成的 latent 上检查分布迁移，避免只证明能够解码被人为加噪的合成数据。

## 3. 阶段 A · 验证源 head 的实际因果效应

**目的**：区别“轨迹清晰但只是可视化”与“消融会改变运动”。

1. 从作者脚本分组中抽取清晰轨迹/弱轨迹、较高/较低归因的候选 head；避免用分组标签替代单头实测。
2. 先在冻结去噪状态下计算头输出投影前激活、投影后真实写入、denoiser velocity 差异。
3. 再选少量候选做早期单步干预继续生成；必要时复现原文的头组消融（不能把头组结果归因到单个头）。
4. 条件分支分别执行 cond-only、uncond-only、both；保存每次 forward 的真实 timestep、branch、头号与层号。

**注意**：此前曾把 L15H2 视作高影响、L9H7 视作低影响的示例；作者公开脚本的归因分组并不支持直接这样标记。这里将它们仅作为可选候选，必须根据单头视频干预重新确认作用类别。

**输出**：少量对照视频、原始 head write、干预前后 denoiser 输出、轨迹与可见失败描述；按 seed 成对记录。

**阶段决定**：若单头效应弱而头组效应显著，转为头组冗余/协同设计，而不是强行选择“最重要的单头”。

## 4. 阶段 B · 精确算子响应分解（主要低成本实验）

对阶段 A 的两个或几个有对照性的源 head，选若干去噪快照（最初优先 1/3/5 步，后加中间/后期作为对照）。

在同一层、同一状态中捕获：

- head pre-output `z_h` 与投影列块 `W_O^(h)`；得到 $U_h$；
- cross-attention 前后状态、FFN 前 `c^+`、time modulation $e_3/e_4/e_5$；
- 有/无 head 的 norm2/AdaLN、Linear1、GELU、Linear2，得到 $\Delta a_j,\Delta m_j,D_{hj}$；
- 全通道写入的合成 $\sum_jD_{hj}$，对照真实 block 差分。

主要关系：

$
B^+-B^-=U_h+\sum_jD_{hj}.
$

严格的数值 oracle：原生 block 两种路径的差分与独立重建差分一致。记录最大绝对误差、相对 L2 误差、dtype；BF16 不硬套 FP64 的理论精度。

**分析输出**：

| 数量 | 目的 |
|---|---|
| $\|U_h\|$、$\|T_s(c^+)-T_s(c^-)\|$ | 输入写入与归一化后有效扰动的差别 |
| 每通道 $\Delta m_j,\|D_{hj}\|$ | Head→FFN 通道响应 |
| $\kappa_h=\|\sum D\|/(\sum\|D\|+\epsilon)$ | 写入方向抵消 |
| 分状态/区域的响应方向余弦与谱 | 是否跨样本/去噪步稳定 |
| 目标区域与背景区域的差分 | 功能是否具有时空选择性 |

优先流式累计 statistics 与候选通道增量，避免全部保存 30 层 × 8960 通道 × 所有时空 token。按 81×480×832、VAE stride (4,8,8)、DiT patch (1,2,2) 估计约 32760 tokens；单层 BF16 FFN hidden 约 560 MiB。

**阶段决定**：式 (A) 若不通过，先修正张量轴/调制/bias/CFG/精度问题；不依据错误的局部差分推进通道消融。

## 5. 阶段 C · 从响应相关到路径因果

选择候选通道集合 $S$。首次检查 Top-16、Top-64、Top-128 三个规模；各集合的选择只使用探索数据。

三个互补的排序/对照：
- 大 $\|D_{hj}\|$：高写入能量；
- 大 $|\langle\nabla Q,D_{hj}\rangle|$：对明确的、可微的下游运动代理 $Q$ 的一阶敏感性；
- 同规模随机集合与写入能量匹配的集合，以及高隐藏激活集合。

**关键**：代理 $Q$ 的物理含义必须明确，例如输出速度场上的对象区域定向变化；不能把模型速度场的范数或注意力相似度默认当作“物理正确性”。若没有可信可微代理，保留能量与随机对照，并直接以完整视频进行少量确认。

执行四组：

$
B(0,\varnothing),\quad B(1,\varnothing),\quad B(0,S),\quad B(1,S),
$

其中 $B(d,S)=B^-+dU_h+\sum_{j\in S}D_{hj}$。

并检查 $B(1,S_{\rm all})=B^+$。先测目标 denoiser 的输出，再对有区分力的候选继续生成完整视频。记录 FFN/直接残差路径的主效应与交互。

**必要性补充**：正常 head 条件下只移除其 FFN 增量，而不把整条 FFN 通道置零；并结合“反向 patching”排除在异常混合状态下碰巧恢复代理分数的解释。

**阶段决定**：

- 少量通道的稳定恢复优于对照：继续原始通道回路。
- 单通道效果弱，成组写入明显：进入输出方向/子空间分析。
- FFN 响应强但运动作用弱：优先分析 head 直接路径与后续 self-attention，不继续扩大通道扫描。
- 模型视频中物体消失/变形：记录为损坏事件，不当作运动减弱的改善。

## 6. 阶段 D · 跨层与跨去噪步追踪

从已验证的源 head/write 出发，依次记录下一层：

1. self-attention 输入/输出及 Q/K/Value 的变化；
2. 后续 FFN 的精确输入输出变化；
3. 选定的中层/末层 velocity prediction 变化。

用 JVP/VJP 作**局部筛选**，用有限幅度的路径 patching 作**因果验证**。跨层变化可能来自多条残差路径；只在某个下游 FFN 中看到差分，不能声称找到了“直接连接”。

去噪过程另开一条轴：固定同一步的 $(z_s,H_s)$ 比较模型输出，随后从同一采样器状态恢复并继续生成。真实 UniPC 等多步采样器的状态 $H_s$ 必须一并控制。

考察同一候选路径在初期/中期/后期的变化。比较不同实验时，按实际噪声级而非主观“第 5 步”等同处理不同采样器或蒸馏设置。

## 7. 阶段 E · 运动表征几何（按证据触发）

仅当对原始 FFN 神经元的解释明显不稳定，或已经发现协同/群体效果时推进。

- 训练逐层/逐去噪时刻的方向 $(\cos\theta,\sin\theta)$、速度大小、位置等 probes；训练/确认数据分离。
- 检查方向解码何时出现、是否在 FFN 前后变化，并用路径干预测试变化是否具有功能作用。
- 从 $\Delta F_h$ 的写入矩阵出发分析 SVD/有效秩/子空间角度，但不能把高方差方向直接解释为运动。
- 以监督运动变量/对比条件构造 task-sensitive subspace；比较单方向、多个正交方向、局部切空间干预。
- 只有原始算子和子空间的解释能力不足时，考虑少数层的 timestep-conditioned transcoder；其保真度与回路归因须在原始模型上单独验证。

## 8. 运动结果与统计定义

**最终视频每个 arm 都保存 MP4**；自动测量附带逐视频的人工复核入口。

| 类型 | 推荐统计 | 重要例外 |
|---|---|---|
| 指令遵循 | 水平/垂直运动的有向位移、目标事件是否出现、动作顺序 | 固定对象与动作，避免把内容变化混入 |
| 运动轨迹 | 物体中心轨迹、速度差分、运动方向、跟踪连续性 | 物体消失/身份漂移单独标记 |
| 物理规律 | 飞行阶段加速度、接触前后速度、碰撞时间与接触位置 | 不同运动模式使用不同判据，弹跳不能全程当自由落体 |
| 外观完整性 | 对象存续/形变/材质变化/背景稳定；人工审查 | 不能用低运动量掩盖外观失败 |
| 整体质量 | 视频质量/语义指标作为补充 | VBench 总分不能代表物理正确性 |

**统计单位**：prompt/scenario × seed 的配对生成；同一个视频中的 frames/tokens/channels 是重复观测，不作为独立重复计数。探索阶段报告每对的效果与分布；确认阶段冻结方向、目标指标、聚合方式与容差，再报告配对差、bootstrap CI 或层级效应估计。物体跟踪失败者不能从分母中悄悄移除。

**独立性**：排序/选 head、选通道所用样本与确认效果的样本必须分开。每次调参均标记探索性，不反向修改已冻结的确认规则。

## 9. 最小执行顺序与推进标准

| 批次 | 计算 | 产出 | 通过后推进 |
|---|---|---|---|
| 0 · 源复核 | 少量 pair seeds 的基础视频、头消融 | 真实 head 效应与分支区别 | 发现至少一种对照性的路径条件 |
| 1 · 算子检查 | 不生成新视频的局部重放 | 头输出投影和 FFN 差分逐项恒等式 | 模块数值 oracle 通过 |
| 2 · 路径探针 | 固定 latent 的 FFN/直接路径恢复 | denoiser 和任务代理变化；匹配对照 | 找到有差异的干预 |
| 3 · 视频行为 | 最有意义的少量完整配对视频 | 指令/轨迹/物理/外观差异 | 真实行为与内部作用方向一致 |
| 4 · 独立验证 | 留出样本 / 新运动类别 | 干预效应稳定性与置信区间 | 可报告可复核的功能回路 |
| 5 · 机制扩展 | 跨层/表征几何/时变 | 较深的解释性机制 | 由前面结果选择，不默认全部执行 |

**停止或转向依据**：先判断当前实验能否区分竞争假说；如果没有，不扩大计算量。如果结果反对 FFN 中介，应明确保存这个局部负结果，并转向注意力或其他下游路径。

## 10. 数据与实验资产契约

建议后续代码按以下语义组织（这些目录目前只是计划，不代表已有实现）：

~~~text
src/
  capture/         head/pre-output, c_plus, modulation, CFG-branch
  operators/       exact finite differences, beta estimates, JVP/VJP
  interventions/   head mask, branch-aware direct/FFN path patching
  analysis/        probe, geometry, trajectory, paired statistics
experiments/
  head_validation/
  local_response/
  causal_paths/
  motion_geometry/
results/
  runs/<run_id>/
    manifest.json
    raw_metrics.json
    operator_checks.json
    interventions.json
    videos/*.mp4
~~~

每个 run manifest 最少记录：

- model/checkpoint ID 和代码 commit；prompt、seed、VAE、resolution、frame_num、CFG、sampler、steps、shift；
- 层、head、隐藏通道索引、token 对应的时空坐标、真正的 timestep 和 CFG branch；
- 被修改算子、干预强度、路径集合、采样器状态复现方式；
- dtype/backend、捕获张量的 shape、完整算子 oracle 与数值误差；
- 轨迹/物理/外观评价方法、失败样本、配对关系和视频路径。

缓存不可凭目录名推断其来源；真实运行日志应把 assets 与 producer 配对。本文没有创建实测 MP4、probe 权重或算子数据。

## 11. 项目层面的完成标准

- 能提供一组**从上游 head 的实际写入到后续运动结果**的可验证干预链，而不是仅提供 activation correlation。
- 能在独立样本中区分至少两种竞争机制（原始通道、分布式协同、attention 主导等），即使结果否定初始假设也如实收束。
- 算子推导、源码绑定、所有生成设置和统计单位足够完整，允许另一研究者复核关键对照。
- 研究贡献以解释和因果控制为主，FFNDS/Q1r2 仅保留数学来源联系。
